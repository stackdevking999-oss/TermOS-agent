# TermOS agent

TermOS agent is an environment-aware Android/Termux agentic system that discovers its tools, reuses proven workflows, executes tasks safely, verifies results, and improves over time.

## What this repo starts with

- a Python package skeleton
- environment discovery stubs
- a skill registry stub
- a simple orchestrator stub
- SQLite-ready storage helpers
- a bootstrap script for Termux

## First milestone

- detect the local environment
- register and reuse skills
- execute safe commands
- verify results
- store task experience
